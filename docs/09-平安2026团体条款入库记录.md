## 转换处理

- 跳过目录块、页码和跨页页眉；清理被 PDF 抽取粘到正文末尾的页码。
- 保留章、节、条和数字编号的父子层级。像 `9.10【机动车】` 这样的紧凑标题也会单独建节点。
- P3721 附表 1 转成可检索的键值行，例如 `七级=40%`，并独立归到 `附表1`。
- 所有文本均来自 PDF 文本层，不需要 OCR。其余非标准表格仍可能需要人工核对，不能把扁平抽取当成版式表格的完整还原。

## 入库与问答

重建向量与 BM25 索引：

```powershell
python scripts/build_index.py --rebuild
python scripts/cli.py products
```

项目保留两份合成示例语料供新 clone 演示。当前本机的索引还包含这四份真实条款；在干净 clone 中则只会包含两个合成产品。网页里选择产品可将提问限定到目标条款；不要把合成示例当作真实保险合同。

当前环境没有模型 API key 或本地模型服务。索引会先用 `hash` 兜底向量构建，BM25 关键词检索可用，但语义检索效果有限；配置 `.env` 中的 embedding API 后必须再次用 `--rebuild`。LLM 仍会显示 Mock 演示状态，配置生成模型 API 并重启服务后才会产生真实模型回答。
