## 一、日常三件事

### 1. 启动系统

```powershell
# 窗口 1（后端，别关）
cd "D:\ds harness\insurance-rag"
uvicorn policyrag.api:app --app-dir src --port 8000

# 窗口 2（前端热更新，改样式时才需要）
cd "D:\ds harness\insurance-rag\web"
npm.cmd run dev
```

打开：
- 落地页 http://127.0.0.1:8000
- 演示页 http://127.0.0.1:8000/app
- 开发模式 http://127.0.0.1:5173

---

### 2. 加新条款（PDF）

```powershell
cd "D:\ds harness\insurance-rag"

# ① 先预览，看识别对不对
python scripts\ingest.py "C:\Users\大兰空\Desktop\你的条款.pdf" --dry-run

# ② 正式入库
python scripts\ingest.py "C:\Users\大兰空\Desktop\你的条款.pdf" --product-name "平安e生保长期医疗险" --doc-type "百万医疗险"

# ③ 重建索引（必须！）
python scripts\build_index.py --rebuild

# ④ 验证
python scripts\cli.py products
```

## 六、切到真实模型（拿到能写进简历的数字）

```powershell
# 真实的向量模型（换完必须 --rebuild）
$env:PR_EMB_PROVIDER="api"
$env:PR_EMB_API_BASE="https://api.siliconflow.cn/v1"
$env:PR_EMB_API_KEY="sk-你的key"
$env:PR_EMB_MODEL="BAAI/bge-m3"

# 真实的生成模型
$env:PR_LLM_PROVIDER="api"
$env:PR_LLM_API_BASE="https://api.deepseek.com/v1"
$env:PR_LLM_API_KEY="sk-你的key"
$env:PR_LLM_MODEL="deepseek-chat"

cd "D:\ds harness\insurance-rag"
python scripts\build_index.py --rebuild
python scripts\eval.py --mode all --gen --judge
```

⚠️ **这些环境变量只对当前窗口有效**。换窗口要重新设，或者用下面的 `.env` 方式。

## 七、环境变量一览

| 变量 | 默认 | 作用 |
|---|---|---|
| `PR_EMB_PROVIDER` | `hash` | `hash`（占位，效果差）/ `api` / `local` |
| `PR_LLM_PROVIDER` | `mock` | `mock`（占位）/ `api` |
| `PR_EMB_API_KEY` / `PR_LLM_API_KEY` | 空 | 接口密钥 |
| `PR_MAX_CHARS` | 800 | 单块最大字数 |
| `PR_MIN_CHARS` | 60 | 单块最小字数 |
| `PR_TOP_K` | 20 | 一阶段召回数量 |
| `PR_TOP_N` | 5 | 送进模型的条款数 |
| `PR_USE_RERANK` | 0 | 是否开重排序 |

## 八、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面显示「索引未就绪」 | **后端没在跑** | 重开后端窗口：`uvicorn policyrag.api:app --app-dir src --port 8000` |
| 加了语料但问不出来 | **索引没重建** | `python scripts\build_index.py --rebuild` |
| `npm` 报"禁止运行脚本" | PowerShell 执行策略 | 用 `npm.cmd` 代替 `npm` |
| PDF 抽不出文本 | 扫描件（图片型） | 先做 OCR，转成文本再用 |
| 识别出 0 条条款 | 标题格式不支持 | 用 `--dry-run` 看读到了什么；标题需独占一行且以「第X条」开头 |
| 「向量模型与索引不匹配」 | 换了 embedding 没重建 | 加 `--rebuild` |
| 端口被占用 | 上次没关干净 | 换端口：`--port 8001` |
